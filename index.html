apk (v3) repositories for BPI-R4 images built by this project.

EasyMesh R6

echo "https://woziwrt.github.io/bpi-r4-deploy/easymesh/packages.adb" > /etc/apk/repositories.d/easymesh.list
apk update --allow-untrusted
apk add   --allow-untrusted easymesh

The index is not signed yet, so --allow-untrusted is needed on both commands.
